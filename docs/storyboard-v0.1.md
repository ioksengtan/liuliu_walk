# 溜溜紀念繪本企劃紀錄

> 專案主題：保存溜溜、爸爸、媽媽、小黑、小白在新竹縣道竹22每天傍晚一起散步的日常，也保存未來搬離後，對竹22這段生活的記憶。\
> 整理日期：2026-08-16

------------------------------------------------------------------------

## 1. 故事的起點

溜溜最近過世了。想做一本繪本紀念它。

故事不是虛構冒險，而是來自真實生活：每天晚上，爸爸、媽媽和溜溜都會到新竹竹22散步。

散步路線開始附近有一戶人家養了一隻小黑狗。小黑沒有被拭著，每當我們出門散步，它就會自然地跟上。

另外還有一隻年紀很小的小白狗，沒有人養。它把小黑當成大哥，所以只要看到小黑出發，也會跟著加入。

於是每天都形成一種不用約定的默契：

**爸爸、媽媽、溜溜、小黑、小白，五個身影會合，一起出去走一圈，然後各自回家。**
