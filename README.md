# 溜溜紀念繪本

五個每天不用約定就會相遇的身影，在竹22的稻田與暮色之間，一起走完一個再普通不過的夏日晚間。

不是為了記錄溜溜如何離開，而是為了記住牠曾經怎麼和我們一起生活。

- **人物：** 爸爸、媽媽、溜溜、小黑、小白
- **地點：** 新竹竹22
- **季節／時間：** 夏季傍晚至入夜
- **形式：** 封面 + 10 個跨頁的小品繪本
- **敘事：** 以光線與時間推進，不靠戲劇事件
- **結尾：** 各自回家／「明天見。」
